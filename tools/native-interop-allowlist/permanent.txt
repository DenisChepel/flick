# The loader.
ui/Flick.Interop/InteropLibrary.cs            NativeLibrary         The loader resolves, loads, checks and frees flick_interop itself and installs the DllImport resolver.
ui/Flick.Interop/InteropLibrary.cs            DllImport             The loader registers the DllImportResolver that points every generated import at the checked library.
ui/Flick.Interop/InteropLibrary.cs            delegate-unmanaged    The loader reads the ABI hash through a function pointer before any generated import may resolve.
ui/Flick.Interop/AssemblyInfo.cs              DllImport             DefaultDllImportSearchPaths for the generated imports of the one native library.
ui/Flick.Interop/Flick.Interop.csproj         DllImport             Project comments that explain where the generated DllImports and their resolver live.

# Callbacks the OS API is shaped around (ABI rule C3): static thunks handed to Rust.

ui/Flick.Interop/*.cs                         delegate-unmanaged    Function pointers to those thunks, passed to the generated exports that take callbacks.
